13. После inject(A) ангуляр найдет provider для A и начнет создавать сервис. Во время создания увидит, что нужен B, затем C, потом D и LoggerService. Когда все зависимости будут созданы, ангуляр соберет сервисы в обратном порядке: LoggerService => D => C => B => A и сохранит каждый экземпляр в кеше Root Injector.

14. Сначала 0, потом 3. До inject(UserService) объектов сервисов нет, потому что сервисы с providedIn: 'root' создаются только при первом inject(). Всего появится 3 объекта, которые будут сохранены в Root Injector.
